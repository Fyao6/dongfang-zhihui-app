服务器数据与浏览器数据

计时和导出

全局计时心跳持续记账；离线不补算中间整段空白，多窗口不重复累计。管理列表展示最近500条记录并显示总数；完整JSON和CSV导出读取全部元数据及计时汇总，不包含自评正文、消息正文或密钥。SQLite在线备份脚本已验证完整性。

关键业务联调闭环

内容配置到APP

运营编辑 → 保存草稿或发布 → 服务端校验并写内容和版本 → APP启动读取public → 应用已发布内容及排序 → 当前页面显示。归档后退出新内容列表；每日一句全空显示准备中。历史抽卡快照与历史预览记录可保留，不等于重新发布归档内容。

学员记录到后台

前台完成身体、生命、情绪、签到或抽卡 → 浏览器保存 → POST records → 后台按owner、kind、day持久化 → 管理页查询元数据或完整导出。网络失败时保留本地结果并提示未同步；当前没有自动重试队列、统一云端读回或全面跨设备恢复。签到和抽卡的同日重复不改写首条服务端结果。

自主发布与审核

作者上传素材 → 保存草稿或提交pending → 后台审核为published或rejected → 公开流只读取published → 作者修改已发布内容需重新审核。下架需要说明并退出公开流。原视频DOM在未发生数据变化的刷新中保留，避免刷新打断播放。

老师服务需求

已登录学员选择已发布老师 → 提交teacherId、未来或当日date、body → 后台出现pending需求 → 运营受理accepted或结束closed → 学员重新读取自身需求并看到真实状态。真实老师资料和服务排班仍需业务方提供。

设备与AI

设备供应商先配置，用户明确同意连接，才接受供应商凭据对应的测量推送；解除授权后拒绝继续写入。本轮通过本地HTTP模拟供应商验证，不代表真实硬件。AI消息由前台messages转换为服务端适配输入；适配单测验证请求及响应解析，未使用真实付费API。

好友与消息

按账号申请好友 → 对方接受 → 才能读取和发送双方消息；第三方账号无权访问。会话轮询仅在相应页面更新，保留正在输入的草稿。
