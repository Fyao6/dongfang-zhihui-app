八字样本核对与临时视图

适用范围
本模块对应需求 B10、B12：提供本人管理员的样本导入、冻结回放、逐字段差异和原生 APP 临时核对工具。软件验证与老师标准答案确认分开记录。老师确认样本数保持 0，专业一致率为未评定；合成用例、导入来源声明、管理员分类建议都不代表老师批准。
当前实施是否已经验收，以 06_验证与后续工作/负责人优化建议-八字样本-实施记录.json 和最终交付核验为准；没有冻结收据时不能以本说明认定完成。

后台使用
通过本地服务打开统一管理后台，使用当前管理员账号进入“八字样本核对”。其他角色不提供该入口，服务端仍检查真实当前角色与本人归属。
选择 UTF-8 JSON 文件，点击“导入文件”。HTTP 请求直接传原始字节，X-EW-Request-ID 保存本次操作身份；不先在浏览器解析或重排 JSON。最多 2 MiB / 100 例，每例规范内容最多 256 KiB、预期字段最多 2000 项。服务端拒绝重复键、危险原型键、非法编码、非有限数字、未知字段、深度或数量超限，不截断后伪称成功。
格式示例见 02_需求与设计参考/八字样本导入模板-合成未确认.json：两例均为合成输入，expected 为空表示未覆盖标准答案；未知时间示例应阻断完整命盘计算。老师团队补充真实标准前，不把模板结果当专业验收。
同一账号、setId、version 的规范内容相同，会返回首次版本，保留首次来源字节 SHA-256 和长度；规范内容不同则拒绝冲突。原始文件字节不持久保存。规范 JSON 导出不能称作原文件逐字节副本。
打开版本后可逐页选择，或“选择全部”；全部选择使用冻结完整顺序，包含未翻页的样本。新建运行会冻结样本版本、有序 caseIds、实际源码清单和服务端环境。记下运行编号，可在“继续已有运行”恢复读取。
每次点击“处理下一个样本”只处理一例。网络结果未知时重试原请求，不更换操作身份冒领下一例。已处理数量包含失败和阻断，不是专业算法通过数量。失败记录不覆盖，复测需另建运行。
结果页分别显示标准化、原始计算索引、流运选择、对照和批注。完整计算保留起运前段与后续九个十年段，各年十二个月及小运；摘要列表不重复装入全部原始对象。原始数据可按大运段读取，索引包含完整规范字节的哈希、长度和分段信息。

APP 临时核对
在结果页点击“打开 APP 临时核对”，URL 只携带运行和样本标识，不放生日或称呼。当前本人管理员读取原始 sampleCase 后，先显示输入、选项和显式 asOfUtc；点击“进入临时核对视图”后，本机 APP 从原始输入独立重算。
该入口不接受服务端 actual/raw 作为命盘输入。临时状态绑定当前账号、个人存储 epoch 和样本上下文；退出、换号或离开命盘会销毁。不覆盖个人生日、命盘缓存、笔记或旧档案，样本模式禁止个人 B11 存档、自动记录和 AI 外发。普通 APP 当前时间及实际修习计时继续使用真实时钟。
每例显式 asOfUtc 用于复现流运、虚岁、回当前与范围外状态。生日未知时间不猜时柱或完整起运表；新共享生辰仍固定 Etc/GMT-8，旧 UTC 与 IANA/DST 仅按明确旧档案参考独立核对，不静默改写。

差异、分类和导出
未提供预期、值为 null、空数组、不适用、暂不可计算分别记录。未覆盖不计通过，不一致不自动断言算法错误。分类默认为 undetermined；input/rule/algorithm/display 均需对应证据。
分类建议只追加，绑定 findingId、具体路径、原指纹、说明及可选复测运行，不改旧报告。algorithm 类别在没有可信同规则标准时仍只是 proposed；display 类别需要同指纹下实际原生 DOM 的列和字段证据。
单例导出默认精确去除出生资料称呼及相关已知名称路径，并标明去除路径、不是完整冻结正文；原指纹仍对应原冻结内容。明确勾选“完整导出时包含出生资料称呼（私有内容）”才返回完整规范结果。其他自由文本不因此视作匿名。数据只在本人主动查看或导出时读取，不写公共初始内容、不发送模型、不缓存到 localStorage。
服务端 domStatus 始终为 not_run；真实浏览器的柱、六列/七列、详情、月份及神煞观察保存在独立本地验证证据，不回填成服务端自己观察，也不代表手机实机或老师审核。

研发与运维
单一纯 JS 工厂被 APP、固定 Python Node worker 与本地 Cloud 使用；原 lunar 1.7.7 库和许可证固定原字节。原生计算适配、标准化、流运、对照、批注、显示和桥接源码由实际清单绑定。构建严格检查全部 21 项受管源码，APP meta 与清单一致；Cloud prepare 拒绝旧 APP，外部描述文件再绑定实际 Cloud HTML，避免自哈希循环。
Python Node 使用固定绝对路径、shell=False、隐藏窗口、最小环境、并发 2、15 秒超时、内部输入最多 6 MiB、输出 4 MiB。HTTP 导入仍限制 2 MiB。缺失或崩溃明确失败，不回退信任客户端结果。实际 Node/ICU/tz 版本可见时记录；Cloud 未暴露的版本为 null，不猜测。
运行领取和最终提交分别核当前管理员、本人、账号状态、清理 epoch、CAS、lease/token、实际实现身份；计算在数据库写锁外进行，最终使用数据库时间核租约，结果、分块、字段、队列、计数与操作回执同事务提交。完成结果不可修改；源码或实际 APP 改变时，未完成运行拒绝混算，另建新运行。
新私有样本域接入本人清理和账号注销续办。清理必须擦除私有正文并增加 epoch 阻止在途作业复活；原冻结不可变约束仅在真实同事务隐私回执授权下例外执行。最小哈希、计数及审计的未知留存期限为 null，不宣称备份、供应商或其他副本已删除。

本地 Cloud 兼容修复
新增样本引用后，媒体引用判断采用同顺序、同条件的平衡 OR 表达式，保留所有显式/未知列和 Unicode 引用、归属与最终事务保护，避免超过 D1 表达式深度限制。传统解读的原生请求使用 manual 模式，并明确拒绝重定向及非 2xx 响应，不把私有字段或授权头转发到第二目标。两项均以本地原生运行时和实际 HTTP 夹具验证，仍不代表真实供应商或生产 R2 已接入。

仍需外部验收
老师规则、至少 30 个明确确认样本和专业一致率目标；藏语母语审校；手机实机；正式生产数据与部署。软件工具验证不替代这些验收。
