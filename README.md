# 东方智慧 APP

本仓库收录当前项目源码、可查看页面、设计资料、后台说明和验证记录。请在包含 `AGENTS.md`、`03_当前APP`、`04_研发源码` 的仓库根目录操作；开发前先阅读 `AGENTS.md`。

## 负责人查看

克隆仓库后，直接打开 [负责人查看页](03_当前APP/发给负责人-东方智慧首页R4.html)，即可离线浏览界面。GitHub 的文件页面不直接运行这套 APP；登录、发布审核、上传和后台管理需启动下面的服务。

仓库应保持私有。负责人需要先获得仓库访问权限，再使用仓库 **Code → HTTPS** 地址克隆。后续在本机仓库运行 `git pull --ff-only` 获取更新，不必反复下载完整压缩包。

## 本机完整互动预览

准备 Python 3.11+，在仓库根目录执行：

```bash
python -m pip install -r "04_研发源码/app/r4/backend/requirements.txt"
python "04_研发源码/app/r4/backend/server.py" --port 8765 --web-root "03_当前APP"
```

打开：

- APP：<http://127.0.0.1:8765/experience>
- 负责人查看页：<http://127.0.0.1:8765/app>
- 公司后台：<http://127.0.0.1:8765/admin>
- 创作者中心：<http://127.0.0.1:8765/creator>

首次使用新数据库时自行创建管理员，没有预设密码。数据库默认生成在 `04_研发源码/app/r4/backend/eastern-wisdom.sqlite3`，不提交到 Git。Windows 也可使用 [启动脚本](05_后台与研发说明/启动APP与后台.cmd)。普通静态 HTTP 服务不能替代此后端。

## 修改与构建

前端源码位于 `04_研发源码/app/r4`：

```bash
python "04_研发源码/app/r4/build.py"
```

输出写入 `03_当前APP`。当前页面和源码都已入库，首次查看不需要重新构建。

Cloud 适配源码位于 `04_研发源码/app/cloud`，要求 Node.js ≥22.13.0：

```bash
python "04_研发源码/app/cloud/prepare.py"
cd "04_研发源码/app/cloud"
npm run install:ci
npm run build
```

首次安装会联网下载锁定依赖及平台二进制；仓库不包含 `node_modules`。修改前端后须先构建 R4，再运行 Cloud prepare。构建不会自动发布；云端运行另需 D1/R2 和运行环境配置，详见 [Cloud 说明](04_研发源码/app/cloud/README.md)。

## 入库范围

保留 `00—07` 分类与当前源码、素材、查看页面和验证资料。环境文件、密钥、会话、SQLite、用户上传数据、依赖和缓存不入库；旧整包和回退压缩包留在原本机目录。

Cloud 子项目在原工作机上的独立 `.git` 历史保留本地；本仓库收录其实际源码文件，不将它作为缺少源码的子模块提交。历史打包校验脚本可能需要本机旧交付归档，不是首次运行 APP 的必要步骤。
