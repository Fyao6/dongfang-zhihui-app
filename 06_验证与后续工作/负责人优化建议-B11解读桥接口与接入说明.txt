版本与来源
已保存源必须是真实本人 lcRecords 行，且与当前 b11Record 完整 canonical 一致。
当前完整 provenance 可关联 current；完整旧 provenance 保留原 manifest/cacheKey/outputFingerprint，
关联仍为 historical、不可复用。旧无 provenance 或损坏记录保持 unbound，绝不用当前 release
重新给旧 result 盖当前版本。只有本次真实新算、calculatedAt 有效、非 readonly、无 b11Record 的
未保存计算可 capture 当前版本；纯辅助 transient id 不保存到档案，对外 recordId 明确 null。
selection 变化、不同结果/存档、release 变化或存档删除后，既有链接为 historical/不可复用。
本机原始 source/result/normalized 只在 WeakMap；纯 metadata 无出生值或回复正文。

保存与恢复
默认 saveConversations=false：仅 WeakMap，不给消息加可枚举绑定字段，不额外 persist。
仅 fresh 与本机最新偏好都仍开启会话保存、原 actor/run/consentEpoch/message/目标计算一致时，
实际新 assistant.baziInterpretation 获得纯元数据，并同步调用原 persist()。原 persist 拒绝或报错
即撤回新属性，仍只内存，不伪称保存成功。不建新库、键、档案或自动保存开关。
字段：schema/origin、accountId、messageId/gatewayJobId/interpretationId、recordId|null、
cacheKey/outputFingerprint/selectedViewFingerprint/replyFingerprint、原 manifest、selection索引/模式、
当时 provider/policy/consent epoch 与 global revision/binding。metadata 不进入 privacy 标签。
刷新只对本来已带 metadata 的本人新 assistant 做 restore，不重写原对象和存储。
restore 校验真实源/完整性/原 manifest、原回复正文 hash、selection hash、新鲜本人授权和 provider
receipt，读请求回来的 actor/run/对象/source/manifest 仍一致；保存撤回、删除、换号或 tamper 拒绝。
已保存源可追溯；未保存源须当前存在同 release 的实际新计算且 cache/output 匹配才恢复。
没有可验证源则 unbound；完整旧源 historical；不同版本/流运不能直接复用。
无 metadata 的原聊天、API/server-only 快照、restored job 继续 unbound，不声称已迁移。
此处 current 仅表示排盘来源/版本匹配，不表示新的供应商调用授权，调用仍每次走原门禁。
